# iCARus

## Про проeкт

**iCARus** — система управління сервісом оренди автомобілів. Система призначена для обліку автомобілів (їхніх моделей та характеристик), клієнтів і бронювань. Вона дозволяє зберігати інформацію про автомобілі та керувати їх бронюванням на обраний період часу.

## Основна ідея

- Зручне управління автомобілями, доступними для оренди.
- Зберігання інформації про клієнтів та їх бронювання.
- Централізоване зберігання основної інформації, яка потрібна для організації оренди автомобілів.

## Структура

- `spec.md` — сутності, атрибути, зв'язки та критерії прийняття
- `model.mmd` — декларативний опис ER-моделі в Mermaid.
- `adr/` — опис архітектурних та модельних рішень.
