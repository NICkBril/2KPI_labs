# Lab 3 — Sequence Diagram

## Про лабораторну

Третя лабораторна робота проєкту iCARus присвячена моделюванню взаємодії між акторами та компонентами системи за допомогою Sequence Diagram.

## Мета

Описати послідовність повідомлень між учасниками системи для сценаріїв обраного Use Case, узгодити діаграми з вимогами та сценаріями Gherkin лабараторної роботи №2.

## Структура

- `spec.md` — опис обраного UC-05, його сценаріїв, учасників взаємодії та критеріїв узгодженості.

- `diagrams/` — вихідні файли трьох діаграм послідовності у форматі PlantUML:
  - `g1-successful-rental.puml` — G-1, успішне створення оренди доступного автомобіля.
  - `g2-guest-reject.puml` — G-2, гість намагається створити оренду і отримує відмову.
  - `g3-car-unavailable.puml` — G-3, відмова через недоступність автомобіля на обраний період.

- `diagrams_photos/` — зображення діаграм послідовності:
  - `g1-successful-rental.png`
  - `g2-guest-reject.png`
  - `g3-car-unavailable.png`

- `adr/0001-sequence-diagram-structure.md` — ADR з ключовими рішеннями: рівень деталізації учасників, перевірка авторизації, правило доступності за статусом автомобіля та захист від подвійного бронювання.
