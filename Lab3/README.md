# Lab 3 — Sequence Diagram

## Про лабораторну

Третя лабораторна робота проєкту iCARus присвячена моделюванню взаємодії між акторами та компонентами системи за допомогою Sequence Diagram.

## Мета

Описати послідовність повідомлень між учасниками системи для сценаріїв обраного Use Case, узгодити діаграми з вимогами та сценаріями Gherkin лабараторної роботи №2.

## Структура

- `spec.md` — опис обраного UC, його сценаріїв та учасників взаємодії.
- `diagrams/` — вихідні файли трьох діаграм послідовності у форматі PlantUML.
- `diagrams_photos/` — зображення діаграм послідовності.
