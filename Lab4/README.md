# Lab 4 — Activity Diagram

## Про лабораторну

Четверта лабораторна робота проєкту iCARus присвячена моделюванню бізнес-процесу за допомогою Activity Diagram.

## Мета

Описати один бізнес-процес системи однією точною діаграмою, узгодити її з Use Case з Lab 2 та діаграмами послідовності з Lab 3.

## Структура

- `spec.md` — опис бізнес-процесу та його основних сценаріїв.
- `payment-process.puml` — вихідний код діаграми діяльності у форматі PlantUML.
- `payment-process.png` — зображення згенерованої діаграми діяльності.
- `adr/0001-activity-diagram-payment-process.md` — архітектурне рішення щодо вибору та побудови діаграми діяльності.
