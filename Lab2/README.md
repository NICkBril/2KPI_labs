# iCARus


# Lab 2 — Requirements and Use Cases

## Про лабораторну

Друга лабораторна робота проекту iCARus присвячена визначенню вимог до системи оренди автомобілів.

## Мета

Описати функціонал системи за допомогою EARS-вимог, User stories, Gherkin-сценаріїв, побудувати діаграму і матрицю трасування вимог.

## Структура

- `spec.md` — актори системи, EARS-вимоги, user stories + Gherkin-сценарії, NFR, уточнення до діаграми та матриця трасування.
- `usecase.puml` — вихідний код Use Case діаграми.
- `usecase_initial.png` — перша версія діаграми, до виправлень після аудиту. Лишив для наглядного порівняння.
- `usecase.png` — фінальна діаграма, відрендерена з `usecase.puml`.
- `adr/0001-use-case-diagram-structure.md` — ADR зі структурою діаграми.
