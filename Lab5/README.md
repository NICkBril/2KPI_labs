# Lab 5 — Component Diagram

## Про лабораторну

П'ята лабораторна робота проєкту iCARus присвячена моделюванню архітектури системи за допомогою Component Diagram.

## Мета

Показати систему iCARus загалом: компоненти, інтерфейси, залежності, межу системи та зовнішні інтеграції. Узгодити архітектуру з моделлю даних, вимогами, взаємодією та процесом з попередніх лабораторних робіт.

## Структура

- `spec.md` — опис архітектури iCARus.
- `component-diagram.puml` — вихідний код діаграми компонентів у форматі PlantUML.
- `component-diagram.png` — зображення діаграми компонентів.
